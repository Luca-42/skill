# 分片条目字段定义

分片文件结构：

```json
{
  "采集时间": "2026-11-12",
  "汇总": "一句话概述本轮情况（可选）",
  "条目": [ { ... }, { ... } ]
}
```

## 条目字段（全部为字符串，缺失填空串，不要用 null）

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `单位` | 用人单位全称或通行简称。**跨轮不可改名** | `中共四川省委组织部（省级机关及其直属机构）` |
| `类型` | `国考` / `省考` / `选调` / `考编` / `央企` / `国企` | `省考` |
| `项目` | 招录项目名，含批次/人数。**跨轮不可改名** | `四川省2027年度省级机关及其直属机构公开考试录用公务员` |
| `公告日期` | 公告发布日 | `2026-10-28` |
| `报名开始` | 报名起始；有确切时刻就带上 | `2026-11-12 09:00` |
| `报名截止` | 报名截止；有确切时刻就带上 | `2026-11-18 18:00` |
| `状态` | `招聘中` / `已结束` / `未开始` / `待确认` | `招聘中` |
| `官网` | 官方公告页或报名系统 | `https://gklx.hrss.tj.gov.cn` |
| `岗位表来源页` | 岗位表所在的公告页（找不到附件时填它） | `https://www.tjdl.gov.cn/...` |
| `岗位表文件` | 本地相对路径，多个用 `;` 分隔，**必须带类别子目录** | `岗位列表/考公/北京市_2027市考_招考简章.xls` |
| `下载状态` | `已下载` / `失败` / `未找到附件` | `已下载` |
| `备注` | 依据、口径、失败原因。**这是审计留痕，宁可长** | `公告原文"报名至11月6日18:00"；官网页 200 复核未改期` |

可选字段：`笔试日期`、`行业`（外企用）。

## 完整示例

```json
{
  "单位": "北京市公务员局",
  "类型": "省考",
  "项目": "北京市各级机关2027年度考试录用公务员",
  "公告日期": "2026-11-09",
  "报名开始": "2026-11-12 09:00",
  "报名截止": "2026-11-18 18:00",
  "笔试日期": "2026-12-06",
  "状态": "招聘中",
  "官网": "https://rsj.beijing.gov.cn/bm/ztzl/gwy/",
  "岗位表来源页": "https://www.bjdj.gov.cn/article/3000213524.html",
  "岗位表文件": "岗位列表/考公/北京市_2027市考_招考简章.xls",
  "下载状态": "已下载",
  "备注": "09:14 实测报名入口已开：专题页 HTTP 200，首屏有『考生报名入口』，落地 fuwu.rsj.beijing.gov.cn/gwy/main 并 302 到统一登录页。招考简章 5 个 sheet 合计 1446 个职位，『招考人数』求和 3054，与公告吻合。人数另有 2809 一说（华图济南题名），官方正文未写总数。"
}
```

## 命名规范

`岗位列表/<考公|考编|央国企>/<单位简称>_<项目简称>_岗位表.<扩展名>`

- 无附件、纯在线岗位库：`<单位简称>_<项目简称>_岗位查询页.html`
- 公告全文里含岗位清单但无独立附件：`<单位简称>_<项目简称>_公告全文.html`

## 为什么字段必须全字符串

`build_list.py` 用统一字符串处理（`parse_date` / `cell()` / 拼接）。
混入数字或 `null` 会让列表格出现 `None`、让日期解析炸掉。这是踩过的坑。
